# Проект "Разработка ядра для интернет-магазина с использованием ООП-подхода для создания сервисов"

## Описание:
Данный проект - это создание ядра для интернет-магазина, в основе которого лежит множество объектов, имеющих атрибуты и методы, и взаимодействующих друг с другом.


## Установка:
### 1. Клонируйте репозиторий: 

        git clone https://github.com/basinanatali-star/pythonProject_OOP

## Использование:
Это учебный проект, поэтому можно использовать его как образец.  

## Тестирование:
Тестирование кода играет важную роль в разработке программного обеспечения. Оно не просто помогает обнаруживать ошибки и проблемы в коде до того, как продукт будет выпущен, но также способствует высокому качеству и надежности программных решений.
    
### Причины важности тестирования:
* Обеспечение качества и надежности.
* Повышение уверенности при внесении изменений.
* Ускорение процесса разработки.
* Обеспечение совместимости и соответствия.

### Модули проекта:
* Модуль Category, содержащий класс Category с определением атрибутов и инициализацией
* Модуль Product, содержащий класс Product с описаниями атрибутов 
  * В модуль Product добавлен класс с расширенными атрибутами, наследник класса Product: Smartphone 
  * В модуль Product добавлен класс с расширенными атрибутами, наследник класса Product: LawnGrass 
  * В модуль Product добавлен класс, содержащий абстрактный класс BaseProduct, который является родительским для класса продуктов
* Модуль, содержащий класс-миксин, который будет при создании объекта печатать в консоль информацию о том, от какого класса и с какими параметрами был создан объект.
